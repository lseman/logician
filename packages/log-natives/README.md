# @logician/log-natives

TypeScript-facing native addon wrapping the `pi-natives` Rust crate
(`crates/pi-natives`), which ports the N-API bindings for `pi-ast`
(ast-grep-powered structural search/rewrite), `pi-edit` (the streaming edit
engine), filesystem search (`pi-walker`-backed glob, regex grep, fuzzy
find), token counting, and bash output minimization (`pi-minimize`) from
oh-my-pi's own `pi-natives` crate. See `crates/README.md` for fork
provenance.

The snapcompact frame renderer (`crates/snapcompact`) is linked into the same
addon but registers its functions itself at load time, so napi's codegen
doesn't emit typings for them. `@logician/log-snapcompact` declares and wraps
them (`src/native.ts`); this package's generated typings don't include them.

## Build

```sh
bun run build        # release build -> index.js, index.d.ts, *.node
bun run build:debug  # debug build, faster to compile
```

The compiled `*.node` binary is platform-specific and gitignored; build it
locally before importing from this package. `index.js`/`index.d.ts` are
generated by the same command and checked in so downstream packages get
types without needing a Rust toolchain.

## Usage

```ts
import { astMatch, diffLines } from "@logician/log-natives";

const diff = diffLines("a\n", "b\n");
const matches = await astMatch({
	source: "function greet(name) { return `hi ${name}`; }",
	lang: "javascript",
	patterns: ["function $NAME($$$ARGS) { $$$BODY }"],
});
```

Consumers: `log-core` (token counting), `log-snapcompact` (frame
rendering), and `log-runtime` (grep/glob/fuzzy tools, the hashline edit
engine, ast-grep tools, bash output minimization).
